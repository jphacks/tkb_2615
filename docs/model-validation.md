# モデルの根拠と検証範囲

このrepositoryにあるのはsimulationを組み立てる基盤であり、避難者の心理・行動・健康や避難所の実運用を予測する完成モデルではありません。ここにある時計、乱数、phase順、hash付きCheckpointはsoftware contractの例です。実世界の妥当性やデータの正確さを保証しません。

## 保持した製品側の参照資料

- [`fixtures/source-manifest.json`](../fixtures/source-manifest.json): 製品側の出典、仮定、モデル版、適用範囲の台帳。
- [`model-sensitivity-a07.json`](model-sensitivity-a07.json): 製品側で実施された小規模な仮定感度分析の機械可読記録。
- [合成条件のpaired計測記録](../benchmarks/results/paired-models-small-synthetic-2026-10-23.md): 製品側コードでの記述的な比較結果。

これらは製品側の実装と合成Scenarioを前提とする参考資料です。このrepositoryのpackageだけでは分析を再実行できず、結果は現実の避難者や避難所についての実測・検証・推奨を示しません。製品の係数、実装内容、適用範囲は製品側の文書とコードを確認してください。

## 評価時の原則

- 実測、文献、聞き取り、合成入力、仮定を区別します。
- 出典が運営課題を示すことと、モデル係数を校正できることを混同しません。
- 比較ではScenario、seed、モデル版、実行条件、出力hashを記録します。
- 少数seedの出力を統計的有意性、因果効果、外部妥当性として説明しません。
- 個人情報や未公開の避難者記録をfixtureやGitに登録しません。

製品側でも心理、医療、安全、社会伝播のモデルは校正済みではありません。結果を現実の住民の予測や支援策の有効性として扱わず、人による確認と適切な専門知識を必要とします。
